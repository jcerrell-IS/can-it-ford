# docs/

`REBUILD_REFERENCE.md` holds the design notes for the reconstruction-to-simulation pipeline.

## References to notes that are not in this repository

Comments in the code and a few READMEs cite dated research notes, such as
`docs/MESH_RECONCILIATION_2026-08-08.md`, and corrections-register entries, such as
"register A6". These are entries in the project's internal research log, which stays in a private
development repository with the per-run records. The citations are kept so that each value or
decision still points to where it was worked out. The facts they support are restated in
[`README.md`](../README.md) and [`FINDINGS.md`](../FINDINGS.md), and the per-run provenance is
in [`data/reproducibility_manifest.json`](../data/reproducibility_manifest.json).

`docs/performance.md`, cited inside `third_party/`, belongs to the upstream mpm-engine project.
