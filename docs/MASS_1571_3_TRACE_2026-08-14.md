# Where 1571.3 kg came from, traced 2026-08-14

Read-only trace of the Rogue mass attributed to job 896273. No file outside this branch
was modified. **DISPATCH 4 owns the register entry; this document does not write it.**

## Verdict, stated first

**1571.3 kg is a WEB-SOURCED figure that was then DERIVED by unit conversion, and the
conversion rounds the wrong way.** It is not measured, not deck-derived, and not
NHTSA-grounded.

Origin: **cars.com, 2020 Nissan Rogue FWD S curb weight 3,464 lb.** Recorded in exactly
one place as a provenance statement, `scripts/class_specific_2026-08-08.sbatch:53-54`:

> `#   Rogue 1571.3 kg is WEB-SOURCED ONLY (2020 Rogue FWD S curb weight 3464 lb,`
> `#   cars.com). The Rogue LS-DYNA deck header states NO mass, unlike the Yaris`
> `#   and Silverado decks. Label it as web-sourced in any writeup; do not present`
> `#   it as deck-derived.`

So the number was **never unsourced**. It was under-indexed: the source is a shell comment,
never a structured field, which is why three sessions could not find it.

## The arithmetic does not close

Computed here, and cross-checked against Wolfram, which returns 1571 kg to 4 significant
figures:

| Quantity | Value |
|---|---|
| 3,464 lb x 0.45359237 (exact international avoirdupois pound) | **1571.243970 kg** |
| Correctly rounded to 1 dp | **1571.2** |
| Value actually used in the repo | **1571.3** |
| Error | **+0.056 kg, +0.0036 percent**, rounded the wrong way |
| Pounds that would give exactly 1571.3 | 3,464.12 lb |

Immaterial physically (0.0036 percent), but it means 1571.3 is not the clean conversion of
any round pound figure, so anyone re-deriving it from 3,464 lb will get 1571.2 and think
they have found a discrepancy.

| Reference | kg | Delta vs 1571.3 |

## Two traps that made this look untraceable

1. **`git log -S"1571.3" --reverse` names the wrong first commit by three weeks.** It
   returns `f85c385`, 2026-07-17, "Add downloaded NCAC vehicle FE models". That is a false
   positive: the matches are **node coordinates in millimetres** inside LS-DYNA `.key`
   meshes, for example `2002376   -2729.5991211     814.5625000    1571.3085938`. The first
   real declaration is `98433fc`, 2026-08-08.
2. **In zsh, an unquoted `--include=*.py` is glob-expanded and the command dies with
   `no matches found`, printing zero hits.** Run verbatim, the prescribed grep reports
   nothing and looks like a clean negative. Quote every `--include` pattern. Separately,
   `timeout` does not exist on this Mac.

`docs/MESH_RECONCILIATION_2026-08-08.md:151` asserts *"1571.3 kg does not appear in project
documentation"* and then supplies the cars.com trace 82 lines later at `:233`. The file
contradicts itself, and the earlier sentence is the one that keeps getting quoted.
