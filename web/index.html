Can It Ford?

Autonomous vehicle flood traversability via reconstruct-to-decide world models.

Given a real flooded road, this project asks whether a specific vehicle can ford the crossing, and looks for the simplest physical abstraction that still answers correctly.

The question is posed as a ladder. Each rung is a cheaper model than the one below it, and the experiment is about finding where a cheaper rung stops being sufficient.

L0
Static depth threshold Depth alone, following NWS Turn Around Don't Drown guidance.
L1
AR&R stationary-vehicle stability, joint rule Depth, velocity and the depth-velocity product must all sit inside the limits for the vehicle class. Thresholds differ by class, so the class matters.
L2
Full physics A warpmpm material point method simulation, weakly compressible water coupled to a rigid vehicle hull. Runs on GPU, not in a browser.

Try it

L0 and L1 are pure arithmetic, so they run live. The interactive demo is hosted on Hugging Face Spaces.

This is not a safety tool. The stability criteria used here are the source report's own draft interim figures for stationary vehicles, not an endorsed safety standard. Nothing on this site should be used to decide whether to drive into floodwater. Turn around, don't drown.

Status

This is active research, not a finished result. Quantitative L2 findings, including their limitations and the resolution behaviour behind them, are recorded in the repository rather than summarised here, so that any number stays next to the caveats it needs.
