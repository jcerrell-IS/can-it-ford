# Track 1 sweep, first version (superseded)

An earlier version of the box-proxy sweep in [`../track1_sweep_v2/`](../track1_sweep_v2/): 36 runs
across three vehicle classes (sedan, SUV, pickup) at a 64-cell grid, one row per run in
`manifest.csv`. Every row has `density_plausible` set to False. Like v2, it is superseded and
excluded from the paper; it is kept as a record. Do not cite its numbers.
