# Handoff Index
APPEND-ONLY. Add lines with `>>` from a shell. Never Edit this file, never Write it, never reflow or correct an existing line. If a line is wrong, append a new line that corrects it.
Why: `>>` opens with `O_APPEND`, so concurrent short appends from different panes all land. Edit and Write read the whole file and write it back whole, which loses one pane's change when two write at once. That race is the reason this pattern exists.
Append a row with:
```bash
printf '| %s | HANDOFF | `%s` | %s | %s |
' \
  "$(date -u '+%Y-%m-%d %H:%M')" "<filename>" "<session>-<pane>" "<one line>" \
  >> .claude/handoffs/INDEX.md
```
Types: `HANDOFF` is a report of work done. `MISSION` is an inbound task assignment from the orchestrator, which may not have been carried out, so never read one as a report. `ARCHIVE` is a frozen snapshot, never edited after creation.
