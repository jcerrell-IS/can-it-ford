# MPM Technical Deep Reference (exhaustive research layer)

## Purpose and how this skill is structured

This skill holds the **full, largely-verbatim content** of every deep Perplexity research report run for the Can It Ford kks32/mpm-engine pipeline, split into topic files under `references/` so this index file stays short and Claude loads only what's needed for a given question. Companion skills: `geoelements-tech-reference` (general PVWM/gsplat/project background, concise), `mpm-render-pipeline` (hands-on production workflow — commands to actually run). This skill is the "why do we believe this" layer underneath both.

**Standing rule, same as the other two skills: never restate a claim from these reference files as current fact without checking the live source first if it's been more than a day or two.** These are point-in-time research captures, not living truth.

## The two live, unresolved disputes (top-level summary, full detail in file 00 and 01)

1. **Does `add_sdf_collider()`/`build_sdf()` actually work in kks32/mpm-engine today?** Disputed between two same-day sources. Default to `Solver.add_box()` for a box vehicle until personally verified live on Vista.
2. **Which render stack is primary?** Not actually contradictory once reconciled — matplotlib+ffmpeg first (proven, zero GPU-context risk), PyVista via `conda install -c conda-forge vtk pyvista` (not pip) for later poster-quality output, after a one-frame smoke test.

## Citation corrections to apply everywhere else in the project (full detail in file 03)

- Shand et al. 2011 AR&R threshold of 0.60 m²/s is specifically the **"Large 4WD"** class, not generic 4WD. The report itself calls its thresholds "draft, interim, informal."
- Smith, Modra & Felder 2019 (DOI:10.1111/jfr3.12527) — confirmed real and correctly cited as-is.
- Luo et al. IJRR (DOI:10.1177/02783649231221580) — online-first Dec 2023, issue date Aug 2024, either is defensible if used consistently.
- `CanItFord_Abstract_FINAL` (Google Doc, modified 2026-06-18) has **zero in-text citations, footnotes, or DOIs** for any of the above as of last check — the citation register lives in research docs, not yet in the abstract.
