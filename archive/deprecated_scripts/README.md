# archive/deprecated_scripts/

Superseded or one-off script snapshots and `.bak` copies of scripts whose live version
still exists elsewhere in the repo.

Kept, not deleted, so the working version of a script can be diffed against an earlier
state if a regression is suspected. Nothing in here is imported or executed by the live
pipeline. The live counterpart of each file still lives at its normal path; only the
backup copy was moved here. See `ARCHIVE_INDEX.md` at the repo root for original paths.
