# Archived: the product-only L1 rule (July 2026)

These scripts and figures apply L1 as the bare hazard product alone, D x V <= 0.60 m2/s. That is
the Large 4WD hazard cap of the AR&R criterion with its depth cap removed, and the project
retracted it: the full criterion needs the class depth cap, the 3.0 m/s velocity cap and the
D x V cap together. Applying the full rule for the car's own class moved 23 of 70 scenarios from
FORD to NO-FORD and none the other way.

They are kept because the July 2026 poster
([`public_release/Cerrell_TACC_42x56.pdf`](../../public_release/Cerrell_TACC_42x56.pdf)) was built
with them. Do not cite these figures. The canonical rule is `vehicle_params.L1_verdict`, and the
corrected figures are the `_JOINTRULE` versions in [`figures/`](../../figures/) and the paper
figures listed in the main [`README.md`](../../README.md).
