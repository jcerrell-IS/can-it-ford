# archive/superseded_docs/

Superseded documentation snapshots: doc backups, one-off exported copies of files that
now live in their canonical location, and dated bundles of older status/CLAUDE.md variants.

Kept, not deleted, because they record what a document said at a point in time. The
canonical, live version of each is elsewhere: installed skills live in `~/.claude/skills/`,
the live session state is `SESSION_STATE.md` at the repo root, etc. See `ARCHIVE_INDEX.md`
at the repo root for original paths and what supersedes each file.
